Note:
This update brings the AI Agent's data-migration flow to the Retail catalog, so admins can bulk-import products with per-branch stock in one CSV. Retail itself gets a smarter create form (SKU-first, auto-generated), an accordion table with per-branch stock nested inline, and a "Sold" column on the product detail. Insights is stripped down to the KPI tiles only. Attendee moves out of a full page into a right-side panel modal launched from the class detail, and the dashboard gets a direct "Attendee" shortcut on Today's classes. The whole app also switches to a single 12-hour clock format everywhere. In the prototype you may still see some 404 pages; that means the page/module/feature is still being developed.
New side for admin: to navigate to admin please change the link to "https://onra-poject.vercel.app/admin/dashboard" and for the instructor side, please change it back to "https://onra-poject.vercel.app/instructor/dashboard"
Interactive experience — This is a fully interactive prototype. Feel free to click, create, edit, and delete items to test the workflows.
Live updates — The prototype uses realistic sample data. Any changes you make apply live as you navigate between different screens.
Session persistence — Any data you create, edit, or cancel survives a page refresh and tab close. Your demo session sticks until you explicitly reset.

1 AI Agent
The chat assistant that answers questions and now imports data for you.
Capabilities:
Retail import — The migration wizard can now bulk-import retail products AND retail categories, including per-branch stock in one CSV.
Per-branch stock columns — A CSV with columns like "stock_Forma Studio (South)" / "stock_Forma Studio (East)" seeds units into each branch automatically.
Handles Numbers.app exports — CSVs saved from Apple Numbers use semicolons instead of commas; the wizard now auto-detects the delimiter so those files import cleanly.
Asks when unsure — If the AI can't tell which module a file belongs to, it now asks you to pick before it starts mapping.
Downloadable invalid-rows report — Any rows that couldn't import now show as a clickable file in Migrations & imports. Hover shows a tooltip, click downloads a CSV with the failed rows and the exact reason for each.
Real counts on the import summary — The wizard's step-4 preview now checks against your existing catalog, so a CSV with SKUs that already exist reads as "duplicates" up front instead of appearing to succeed then silently failing.
Hides during bulk actions — The floating AI button now hides itself the moment you check a row for bulk actions, so it never covers the bulk-action bar at the bottom of the screen.

2 Retail
The full retail catalog, now easier to browse and import.
Capabilities:
Accordion table — Every retail row expands inline to show per-branch stock and per-branch units sold, without leaving the list.
Sold column on Stock by branch — The product detail page's Stock by branch tab now has a "Sold" column next to units-on-hand.
SKU-first create form — SKU sits at the top of the create/edit form, name second. The SKU auto-generates from the category prefix + product initials (e.g. "APP-OST-001") and shows a real value in the field from the moment you open the form. You can type your own to override.
Live duplicate check — If you type or paste a SKU that already exists, the field turns red with the message right below — no submit-then-fail surprise.
Inline "+ Create category" — Every place that picks a Retail category (the product form's category dropdown, the retail-categories admin page, etc.) has a "+ Create category" button at the top of the dropdown. Opens the same category modal without leaving the flow.
Moved under Products & pricing — Retail categories now sits in the sidebar right under Retail (matching the Classes → Templates + Categories pattern), out of the deep Settings menu.
Import stays visible on Retail — Retail bulk-imports happen often enough that the Import icon button stays visible in the toolbar even when the catalog has data. Every other module hides Import once it has rows.
Round-trip export/import — CSV export now writes one stock column per active branch (stock_<Branch Name>), plus Unit cost, Description, and Image URL — so exporting, editing in a spreadsheet, and re-importing preserves everything without re-keying.
Softer low-stock chip — The low-stock indicator switched from a red-adjacent orange to a lighter yellow, so it stops looking like a critical error.

3 Insights
The at-a-glance KPI overview across every category.
Capabilities:
Tiles only — Every tab (Financial, Customer, Classes, Private sessions, Recovery, Marketing) shows just the KPI cards now. The chart-widget grid below the cards was removed — the Dashboard is where charts live.
Same tab strip and filters — Location picker, search, and date range all still work exactly as before; only the widget grid was cut.

4 Attendee
Marking who showed up for today's classes.
Capabilities:
Now a right-side panel — Opening a class from Today's classes slides in a right-side panel with the roster, instead of pushing you to a separate full page.
Focused on today — The main Attendee page drops the Day/Week toggle and the day picker. It shows today's classes only, with a clear date header at the top.
Simpler class detail — Name-based title at the top, filter and tabs removed, "Present all" moved into flow. The list is a single "Participants" section with a search bar.
Present state sticks — Once you've marked everyone present, the Present-all action goes away — no more re-marking the same class. The status also reflects instantly on the class schedule detail on the admin side.
Opens in a new tab from admin — The class schedule detail on the admin side now has an Attendee tab that opens the full attendee flow in a new browser tab, so front-desk staff can leave the roster open on a second screen.

5 Dashboard
The Today's classes card on the admin dashboard.
Capabilities:
Attendee shortcut — Every card in Today's classes now has a small "Attendee" button that opens the attendee roster panel for that class directly, sitting right before the "See all" link.

6 Class Schedule
The class detail page on the admin side.
Capabilities:
Attendee tab — The class schedule detail page gains an Attendee tab that opens the attendee flow for that class in a new browser tab. Marking present there reflects back on this page instantly.

General updates
Empty-state Import on every list — When a list module is empty (no rows, no active filter), an Import icon button now shows in the toolbar right after Filter, opening the AI Agent's Migrate data flow. Once the list has data, the button hides and Add new is the only entry point — Retail is the exception where Import always shows.
Consistent "Total" tile — Every list toolbar across admin, instructor, and detail-page inner tabs now uses one canonical Total tile — a small light-gray "Total" label above a larger dark count. Sizes were mixed before.
12-hour time everywhere — Every schedule and appointment time in the app now reads in the same "5:00 - 6:00 PM" format. Also applies to the customer app.
Create category inline from every dropdown — Every class-category picker across the app (create/edit class schedule, private session, recovery & wellness, class template, and instructor's categories on the staff form) has a "+ Create class category" button at the top of the dropdown so admins never have to leave the creation flow.
Dropdowns no longer clip — Dropdowns on long forms (Class category on private/recovery, class schedule, instructor categories) were getting cut off at the bottom of scrollable form cards. Now they always fit the visible area and scroll internally when the list is long.

Interactive experience — This is a fully interactive prototype. Feel free to click, create, edit, and delete items to test the workflows.
Live updates — The prototype uses realistic sample data. Any changes you make apply live as you navigate between different screens.
Session persistence — Any data you create, edit, or cancel survives a page refresh and tab close. Your demo session sticks until you explicitly reset.

1 Customers
Rebuilds a customer's booking history to read like the schedule, and adds downloads inside their profile.
Capabilities:
Booking history matches the schedule — The history table now uses the same layout as the Schedule list: date & time, class name (with instructor), Type, Location, Rating, and Status.
Session type at a glance — Each booking now shows its Type — Classes, Private, or Recovery — in its own column.
Rebuilt history filter — Filter a customer's history by Type, date range, Status, time of day, Instructor, and Category, matching the schedule's filters.
Download a customer's records — Export that customer's Plans, Payments, Bookings, Referrals, and Agreements straight from their profile tabs.

2 Staff & Payroll
Adds session type to the payroll breakdown and fixes the shifts download.
Capabilities:
Type column in payroll details — The payroll details table now shows each session's Type (Classes / Private / Recovery) between Class name and Attendance.
Shifts download fixed — Downloading the shift list now gives the shifts you're actually looking at, respecting your filters, instead of the wrong data.

3 Schedule
Fixes class cards being cut off near closing time.
Capabilities:
No more cut-off cards — On the day and week views, a class that runs close to the branch's closing time now shows in full instead of being clipped.

4 Analytics & Reports
Simplifies the report download menu.
Capabilities:
Familiar download menu — Reports now download from the same CSV / Excel / PDF menu used everywhere else, with the earlier technical labels removed. The extra ID columns are still available on demand from "Select columns."

5 Dashboard
Adds Excel to the performance download.
Capabilities:
Excel for performance — The Dashboard performance report now downloads as Excel as well as CSV.

General updates
Download as Excel everywhere — Every list in the admin can now download as Excel or CSV, instead of CSV only.
Download buttons added — Locations & branches, Pay rates, Promo codes, Marketing campaigns, Announcements, Services, Class categories, Staff shifts, and gift-card holders can now be downloaded — screens that had no download before.
Ready for a real system — Every download now quietly includes each record's reference details, so your data can be moved into a full system later without losing how records connect.
Retail download fixed — Archived products are now included in the download, and the button no longer greys out when only archived products remain.
Tidied up — Removed a download that didn't belong on the Notifications settings page.

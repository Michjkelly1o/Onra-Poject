Note:
This update teaches the AI Agent to build a class schedule for you right inside the chat (early preview — class schedules only for now). Retail products can now carry sizes, live alongside their categories on one tabbed page, and filter by location. Gift cards now work end-to-end — bought and redeemed at the front desk and in the member app — and both gift-card and retail sales count toward staff commission. Insights and the Dashboard get clearer revenue tiles, and every report now accounts for retail correctly. In the prototype you may still see some 404 pages; that means the page/module/feature is still being developed.
New side for admin: to navigate to admin please change the link to "https://onra-poject.vercel.app/admin/dashboard" and for the instructor side, please change it back to "https://onra-poject.vercel.app/instructor/dashboard"
Interactive experience — This is a fully interactive prototype. Feel free to click, create, edit, and delete items to test the workflows.
Live updates — The prototype uses realistic sample data. Any changes you make apply live as you navigate between different screens.
Session persistence — Any data you create, edit, or cancel survives a page refresh and tab close. Your demo session sticks until you explicitly reset.

1 AI Agent
The chat assistant, now able to build a class schedule for you (early preview).
Capabilities:
Create a class in chat — Ask the assistant to add a class and it walks you through template, room, equipment, instructor, spots, and timing, then publishes the schedule. Class schedules only for now; private and recovery sessions come next.
Same pickers as the full form — Room, instructor (with rating and reviews), and spots are chosen right in the chat using the same controls as the Create class screen.
Single or recurring — Set a one-off class or a repeating series — pick the days, times, start date, and how it ends — without leaving the chat.
Confirm before it publishes — A clear "Are you ready to publish?" step appears above the message box so nothing goes live until you say so.
Never covers the bulk bar — The floating assistant button now hides the moment you select rows for a bulk action, so it never sits on top of the bulk-action bar.

2 Retail
The retail catalog, now with sizes, one home, and location filtering.
Capabilities:
Products and categories in one place — Retail and its categories now live on a single page with "Products" and "Categories" tabs, matching the Memberships & Packages layout.
Product sizes — A product can carry sizes — Small, Medium, Large, or any label you type. Stock is counted per size at each branch, and the cashier picks a size at checkout.
Sizes on the product page — The product detail shows the sizes it comes in and a per-size stock breakdown for every branch.
Location filter — Filter the retail list by branch to see one location's stock at a glance.
Right branch stock at the till — The stock shown on each retail card in the Point of Sale now matches the branch you're actually selling from.

3 Point of Sale
Selling gift cards and retail, now fully connected.
Capabilities:
Gift cards work end-to-end — A gift card can now be bought and redeemed on both the admin side and the member app, front desk to phone.
Shows in Payment history and can be refunded — A gift-card sale is a real transaction: it appears in the customer's Payment history and can be refunded as long as the balance hasn't been used yet.
Commission on gift cards and retail — Gift-card and retail sales now count toward staff commission, alongside memberships and packages.

4 Insights
Clearer revenue tiles across every tab.
Capabilities:
Simpler revenue naming — "Gross revenue" is gone, and "Net revenue" is now simply "Revenue" (the same explanation still shows on hover).
Classes tab tiles — Sales and Revenue now lead as the first two tiles, with Revenue per class as the third.
Private and Recovery tiles — Both now lead with Sales and Revenue as their first two tiles.
Respects your filters — Every tile updates correctly when you change the location or date range.

5 Dashboard
Cleaner labels on the Today view.
Capabilities:
Shorter tile names — On Today, "Total sales" is now "Sales" and "Total revenue" is now "Revenue".

6 Reports
Every report now accounts for the new Retail module.
Capabilities:
Retail included everywhere — Reports, tax rates, and the related screens were updated so retail is fully covered across the board.
Accurate totals — Retail sales are counted once, so revenue totals and the payments view stay correct.
Clearer label — The "Transactions" measure is now "Line items".

General updates
"+ Add" everywhere — Every "add new" button across admin and instructor now reads a simple "+ Add".
Products & pricing reordered — The menu now runs Memberships & packages, Private sessions, Recovery & wellness, Retail, Gift cards.
Simpler Private and Recovery lists — The status/category filter was removed from Private sessions and Recovery & wellness; search and location stay.
Detail panels fit their content — The right-side info panel on detail pages now sizes to fit all of its info and actions, so both sides of the page stay the same height instead of scrolling.
Smarter search — Search now handles hyphenated names (searching "Al Sayed" finds "Al-Sayed") and multi-word searches (searching "Forma East" finds "Forma Studio (East)").

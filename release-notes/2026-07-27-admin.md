1 AI Agent
The in-app assistant that helps admins ask questions about the studio's data and migrate spreadsheets in. This update is mostly a stability and polish pass on top of the audit we ran end to end.
Capabilities:
Migration accepts CSV, XLSX, XLS, PDF — Attach one of the four in Migration mode and it goes straight in. Everything else is politely refused right at the file picker.
File type icons on attachments — Each attached file shows its real type icon (CSV, XLSX, PDF, etc.) in the composer and in the sent-message bubble, so nothing looks like a CSV when it isn't.
Cleaner CSV parsing — CSVs with commas inside quoted values (addresses, notes, product names) now import correctly instead of splitting mid-cell.
Upload size in sync — The file size limit the assistant enforces matches the one the server enforces, so a file that looks like it should go through actually does.
Migration & Imports history — Duplicate entries no longer stack up in Settings → Migration & imports; each import lands as one clean row.
Focused conversation flow — When you're in Migration mode, the assistant no longer stacks unrelated insight questions on top of your migration task, and long conversations don't loop when you close and reopen the panel.
Sidebar chip context-aware — The AI Agent chip in the sidebar hides while you're already inside the AI Agent, so it doesn't point back at itself.
Report export — PDF exports (Insights, KPI) no longer crash the conversation; they save straight to your device like CSV and XLSX do.

2 Schedule
The class + appointment planner. This update tightens the list view and cleans up appointment actions so admins spend less time hunting for the right button.
Capabilities:
Flexible badge in class type column — Flexible appointments now carry a "Flexible" badge in the class type column of the schedule list, so the difference between fixed classes and flexible ones is visible at a glance.
Upcoming and Past tabs — The schedule list gets Upcoming and Past tabs, reusing the same sorting behaviour the customer bookings list uses. Older classes stop cluttering the default view.
Reassign inside appointment actions — Reassigning an appointment to a different instructor now sits inside the appointment's action menu, using the same add-customer modal pattern the rest of the module uses. One consistent way to reassign, no more hidden entry points.

3 Attendee
Brand new module for taking attendance on the studio floor. Reuses the schedule module's calendar chrome so admins already know how it works.
Capabilities:
Entry point on the schedule — A top-header button on the Schedule module opens the Attendee route. Same location, no navigation retraining.
Day and Week views — The Attendee list borrows the same day and week views the Schedule module uses, filtered down to ongoing and upcoming classes only, and pinned to the device's current time so "today" is always right.
Class details with attendee cards — Opening a class shows every attendee as a card. Marking someone present runs through a two-step Present → Success flow so the attendance is confirmed before it commits, and the attendee card shows a clear "Present" state afterwards.
List, filter, and search — Standard filter side panel + search bar match every other admin module, so filtering by branch, class, or instructor works the same way it does everywhere else.

4 Staff & Shifts
The staff directory + shift scheduler. This update is mostly quality-of-life on the pay rate wizard and the staff detail page.
Capabilities:
Pay rate detail tab — The pay rate module gets a dedicated detail tab, so pay rate context (which instructors are on it, the current rate, notes) sits in one place instead of scattering across the module.
Multi-config instructor pay rates during staff creation — When creating a new instructor, the pay rate step now supports multiple configurations in a single flow. No more back-and-forth to assign a second pay rate.
Working hours default to branch hours — When a staff member has no shift assigned yet, the working hours block on their profile falls back to the branch's operating hours instead of rendering empty. Reads correctly on day one of a hire.

General updates
Sticky filters across admin — Once you apply filters on a list, they stay put when you open a detail page and navigate back. No re-selecting the branch and status every time you check a record.

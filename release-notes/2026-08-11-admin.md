Interactive experience — This is a fully interactive prototype. Feel free to click, create, edit, and delete items to test the workflows.
Live updates — The prototype uses realistic sample data. Any changes you make apply live as you navigate between different screens.
Session persistence — Any data you create, edit, or cancel survives a page refresh and tab close. Your demo session sticks until you explicitly reset.

1 Dashboard
The at-a-glance view of the studio — today's activity, performance over time, and things that need attention.
Capabilities:
Sales vs Revenue, defined clearly — Sales is the full value of what's sold; Revenue is the value of credits actually used. The two now mean the same thing on Today, on Performance, and in Reports.
Renewals count matches its list — The "up for renewal" card and the pop-up it opens now show the same number.
Every chart runs on live data — Revenue, sales by product, memberships, credits, class bookings, attendance, private and recovery, and marketing charts are all driven by real studio activity and follow the location and date filters.
Clearer charts — Long labels no longer overlap, and a chart shows a friendly "no data" message when a filter has nothing to show instead of an empty box.
Tidier Today view — Removed the redundant time shown next to each session.

2 Insights
The studio's numbers in one place — Financial, Customer, Classes, Private, Recovery, and Marketing.
Capabilities:
One Insights page — The old placeholder page is gone; the live Insights page now carries the name everywhere it appears — the menu, the breadcrumb, and search.
Every number is real — All the metric tiles are calculated from the studio's actual data and follow the location and date filters.
Corrected figures — Recurring revenue, average revenue per member, active-member counts, waitlist conversions, and the private and recovery figures are now accurate.

3 Reports
The detailed, exportable view of sales, revenue, and memberships.
Capabilities:
Only settled payments count as sales — Failed and pending payments no longer inflate sales totals or the tax figures.
Accurate revenue recognition — Packages bought in multiples and each plan's real term are now counted correctly, and the Revenue Recognition report reflects real earned revenue.
Safer product deletes — A product with any history can only be archived, never deleted, so past records stay intact.

4 Customers
The full customer list and profiles, now organised around what's actually happening with each customer.
Capabilities:
No Status column — "Active" told you nothing (everyone in the list is active), so it's gone.
Lead / Member / Inactive tabs — Grouped by the customer's wallet: a Lead has never bought anything, a Member has something live right now, and Inactive means they bought before but nothing is live today.
Archived is a place, not a status — Archived customers leave the list, its counts, search, and campaigns, but keep their full history and their access is never touched. If they book again from their own account, they return automatically.
Archived section on the list — Archived customers appear in a collapsible "Archived customer" section below the main list, matching its height with its own paging — no separate screen to hunt for.

5 Class Management
Scheduling and managing every session — classes, private sessions, and recovery.
Capabilities:
Clearer cancel wording — Updated the message shown when cancelling a session, across every session type.
Clearer cancel button — Updated the confirm button in the cancel dialog, across every session type.

General updates
Collapsed menu fly-outs — When the sidebar is minimized, hovering a menu that has sub-items opens its list to the right so you can jump straight to a page; the Settings menu closes on its own when you move to another menu.
Referrals — "Referral program" is now simply "Referrals".
New menu placeholders — Announcements and Events have been added to the menu; they open a "coming soon" page for now while they're being built.
Cleaner AI Agent look — Removed the white circle behind the Onra logo in the "Ask AI Agent" button and the floating chat bubble.
